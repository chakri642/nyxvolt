# Music Library

Drop MP3 tracks into these category folders. The AI music selector picks one that matches the movie clip's vibe.

## Categories

- `hype_drop/` — hard-hitting phonk, EDM drops, trap. For action scenes, fights, chases.
- `epic_buildup/` — orchestral, cinematic, epic scores. For dramatic reveals, hero moments.
- `melancholic/` — sad piano, emotional strings. For sad, reflective, emotional scenes.
- `dark_phonk/` — aggressive dark phonk, drift phonk. For villain scenes, sigma edits.
- `motivational/` — uplifting build-ups, gym motivation. For training, victory moments.

## Where to get music

**IMPORTANT: Use royalty-free tracks or Instagram will mute your reel.**

Free sources:
- **YouTube Audio Library** — https://studio.youtube.com/channel/UC/music
- **Uppbeat** — https://uppbeat.io (free with attribution)
- **Pixabay Music** — https://pixabay.com/music/
- **Free Music Archive** — https://freemusicarchive.org

For phonk/trap specifically, search on YouTube:
- "no copyright phonk"
- "no copyright drift phonk"
- "no copyright hype trap"

Then convert to MP3 via a yt-dlp or online converter.

## Minimum recommended

Start with **3 tracks per category** (15 total) so the AI has variety. More = better variety.

## File names

Names don't matter. Any `.mp3` file in the folder works.
